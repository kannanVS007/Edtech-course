# Become A Skiller 🚀
### The Premium Bilingual EdTech Platform for Modern Engineers

**Become A Skiller** is a high-performance, enterprise-grade Learning Management System (LMS) designed specifically for the Tamil and English-speaking developer community. It bridges the gap between global technical standards and regional language mastery.

---

## 🌟 Vision
To provide structured, high-quality technical education in Tamil & English, enabling the next generation of engineers to master coding, UI/UX, and AI through a premium, distraction-free interface.

---

## 🛠 Tech Stack

### Frontend
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS (Glassmorphism & Premium Dark Mode)
- **Animations**: Framer Motion
- **State Management**: Zustand (Multi-language & Auth state)
- **Icons**: Lucide React
- **Authentication**: Google OAuth 2.0 & GitHub Integration

### Backend
- **Runtime**: Node.js & Express
- **Database**: MongoDB (Mongoose ODM)
- **Security**: JWT (JSON Web Tokens), Bcrypt.js, Helmet, Rate-limiting
- **Validation**: Zod / Joi

---

## 💎 Core Features

### 1. 🌍 Seamless Bilingual Experience
- **Real-time Language Toggle**: Switch between **Tamil** and **English** instantly without page reloads.
- **Localized Technical Content**: High-quality translation for technical terms across the entire platform.

### 2. 🛡 Elite Admin Control (Skiller Ecosystem)
- **Unified Admin Panel**: Manage users, courses, and modules from a single sophisticated interface.
- **Dynamic Stats**: Real-time KPI cards showing total users, active courses, and platform engagement.
- **User Management**: Advanced filtering, role assignment (Admin/User), and account security controls.

### 3. 📱 Dynamic Learning Interface
- **Top Programs Slider**: An interactive, responsive slider showcasing elite Tamil tech channels (Balachandra, Code IO, JVL Code, etc.).
- **Progress Tracking**: Visual indicators of learning paths and module completion.
- **Premium UX**: Mobile-first design with smooth transitions and a "glassmorphism" aesthetic.

### 4. 🔐 Secure Multi-Channel Auth
- One-click login with **Google** and **GitHub**.
- Secure email/password authentication with encrypted storage.

## 💻 Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kannanVS007/Edtech-course.git
   ```

2. **Backend Setup**:
   ```bash
   cd server
   npm install
   # Create a .env file with MONGODB_URI, JWT_SECRET, GOOGLE_CLIENT_ID, etc.
   npm start
   ```

3. **Frontend Setup**:
   ```bash
   cd client
   npm install
   # Create a .env.local with NEXT_PUBLIC_API_URL and GOOGLE_CLIENT_ID
   npm run dev
   ```
